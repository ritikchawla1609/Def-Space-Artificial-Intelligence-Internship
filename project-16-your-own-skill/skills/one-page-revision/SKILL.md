# One-Page Revision Cheat Sheet Skill (`/one-page-revision`)

## Purpose
Transform verbose, dense textbook chapters into a high-yield single-page revision cheat sheet engineered for last-minute exam prep.

## Content Architecture
1. **Core Laws & Axioms** (Top 3 foundational principles in 1 sentence each).
2. **Formula Matrix** (Equations, variable definitions, and SI units).
3. **Deadly Exam Traps** (Subtle misconceptions that cost marks).
4. **ASCII Memory Map / Diagram** (Visual mental anchor).
5. **5-Question Rapid Check** (Quick recall test with answers inverted).
